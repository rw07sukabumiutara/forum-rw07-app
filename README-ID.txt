PAKET AWAL PWA FORUM RW 07 SUKABUMI UTARA

Isi:
- index.html: halaman pembuka aplikasi
- manifest.json: nama, ikon, dan pengaturan instalasi
- service-worker.js: cache dasar untuk halaman aplikasi
- icons/: ikon aplikasi

PENTING:
1. Paket ini perlu diunggah ke hosting HTTPS seperti GitHub Pages sebelum bisa dipasang sebagai PWA.
2. Ikon contoh harus diganti dengan logo final RW 07 berukuran 192x192 dan 512x512 piksel, nama file tetap icon-192.png dan icon-512.png.
3. Aplikasi ini adalah pintu masuk ke Blogspot. Artikel tetap dikelola di Blogspot dan memerlukan internet.
4. Jangan ubah nama file atau susunan folder kecuali manifest.json dan index.html ikut diperbarui.
